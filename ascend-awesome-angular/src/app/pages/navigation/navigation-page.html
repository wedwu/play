 Never shown. Overview Security Support Vertical tab placement, useful for settings screens. Publishing is CI-only; no static tokens are stored. Current major plus the previous major receive fixes. What ships in the package? Two stylesheets and two scripts, plus the Web Awesome asset tree the loader resolves against. How is versioning handled? Strict semver. A Web Awesome major upgrade always forces a package major. Can I use it without a bundler? Yes — serve the self-contained bundle and the asset tree from your static pipeline.
