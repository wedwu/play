# Changelog

All notable changes to `@ascend/ascendawesome` are documented here.
Format follows [Keep a Changelog](https://keepachangelog.com); versioning follows [semver](https://semver.org).

## [4.2.0] - 2026-08-04

### Added
- Initial NPM release. Package contents match CDN `/lts/` build 4.2.0.
- Ascend theme CSS over Web Awesome base styles; cherry-pickable component re-exports; self-contained `dist-cdn` bundle for non-bundled apps.

### Dependencies
- Bundled Web Awesome version: `@awesome.me/webawesome@3.11.0` (exact pin).
